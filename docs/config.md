# 配置说明

配置文件在 `~/Library/Application Support/NotchPad/config.json`。最方便的打开方式：点面板右上角 **⋯ › 编辑配置文件**。

改完保存，下次展开刘海就生效。如果写错了，面板顶上会出现一行黄字说明哪里有问题，同时先用默认配置顶着，不会丢数据。

> 用「文本编辑」改的话，它可能会把引号自动换成弯引号（“ ”）。刘海记能识别这种情况，不用担心。

## 整体结构

```json
{
  "language": "zh",
  "tabs": [ ... ],
  "panel": { "width": 560, "height": 420 }
}
```

- `language`（可以不写）：界面语言，`"zh"` 或 `"en"`。不写就跟系统语言走。系统是英文但想用中文界面，就写 `"zh"`；也可以在 **⋯ › 界面语言** 里切换，会自动重启。
- `tabs`：从左到右的几个 tab，最多 5 个。
- `panel`（可以不写）：展开后面板的宽和高，单位是点。默认 560 × 420。

## 每个 tab 都有的字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `type` | ✓ | 积木类型：`pipeline`（流水线）、`sections`（分段清单）、`jots`（速记） |
| `title` | ✓ | tab 上显示的名字，越短越好 |
| `color` | | 这个 tab 的颜色，比如 `"#42FF8C"`。不写就按顺序用默认的几个荧光色 |
| `placeholder` | | 输入框里的提示文字 |

## 流水线 `pipeline`

几段按顺序往下走，最后一段之后是「完成」。点圆圈往下一段走；完成的点一下会退回原来那段。

| 字段 | 说明 |
|---|---|
| `stages` | 从上到下的几段，每段是 `{ "title": "显示名", "list": "提醒事项里的列表名" }`。`list` 不写就和 `title` 一样 |
| `doneTitle` | 「完成」那一段叫什么，比如 `"已拍"`。只显示最近 10 条，旁边写着本月完成了几条 |

在提醒事项里，每一段是一个列表，「完成」就是勾掉。所以在手机上把一条从「选题」列表移到「待拍」列表，刘海里它也会跟着换段。

## 分段清单 `sections`

几段并列的待办。点圆圈勾掉，勾掉的沉到这一段下面，只显示今天勾掉的。

| 字段 | 说明 |
|---|---|
| `sections` | 几段，每段是 `{ "title": "显示名", "list": "列表名", "color": "#FF61B3" }`。`list`、`color` 都可以不写 |
| `pinned` | 可以不写。置顶卡片，见下面 |

只有一段时，不显示段落标题，看起来就是一个普通的待办清单。

### 置顶卡片 `pinned`

在清单顶上显示一个 Markdown 文件里某个标题下面的列表，只读，从不写入。

| 字段 | 说明 |
|---|---|
| `file` | 文件路径。以 `/` 或 `~` 开头是完整路径；否则指配置文件旁边的文件，比如 `"goals.md"` |
| `heading` | 读哪个标题下面的内容，比如 `"本月重点"`。只要标题里包含这几个字就算 |
| `title` | 卡片上显示的名字，不写就用 `heading` |

文件里这样写：

```markdown
## 本月重点 (2026-10)
- 【IP】每周发两条内容
- 【学习】把剪辑课学完
- [x] 已经做完的会变灰、划掉
```

- 每行开头的 `【IP】` 或 `[IP]` 会显示成左边的小标签。
- 标题里写上年月（`2026-10`），过了这个月，卡片上会提示「该更新了」。
- 文件在 Obsidian 库里的话，点卡片右上角的 ↗ 会用 Obsidian 打开。

## 速记 `jots`

| 字段 | 说明 |
|---|---|
| `folder` | 存到备忘录里哪个文件夹（在 iCloud 账户下），不写就用 `title`。没有这个文件夹会自动建 |

每条速记是一条单独的笔记，第一行就是笔记标题。

## 小提示

- **列表不存在会自动建**，建在提醒事项的默认账户里（一般是 iCloud）。
- **改列表名要两边一起改**：先在「提醒事项」里把列表改名，再改配置里的 `list`。只改配置的话，会新建一个空列表，原来的条目还留在旧列表里。
- 不同 tab 可以用同一个列表。
- 想恢复：**⋯ › 换一套预设** 会把现在的配置备份成 `config.backup.json`，再换成预设。

## 例子

**读书流水线**：

```json
{
  "type": "pipeline",
  "title": "读书",
  "color": "#FFCC47",
  "placeholder": "想读的书，回车保存",
  "stages": [
    { "title": "想读", "list": "书单·想读" },
    { "title": "在读", "list": "书单·在读" }
  ],
  "doneTitle": "读完"
}
```

**置顶卡片读 Obsidian 里的目标文件**：

```json
"pinned": {
  "title": "本月重点",
  "file": "~/Documents/我的库/目标.md",
  "heading": "月度目标"
}
```
